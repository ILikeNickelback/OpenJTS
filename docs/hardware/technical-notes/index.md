# Technical notes

This section details the technical choices for the different modules used in the JTS.

- The LED control note gives information on the LEDs used and how they are controlled.
- The optical transmission note gives information on how the light is transmitted and received.
- The measurement strategy note gives information on how the signal is acquired.
- The preamp design note gives information on how the preamp was designed.
- The VCCS design note gives information on how the VCCS was designed.
- The waveform generation note gives information on how the actinic, detection and trigger waveforms are generated.
